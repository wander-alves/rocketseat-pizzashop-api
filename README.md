# Rocketseat - pizzashop-api

## About

This API is part of a project from Rocketseat Education's Bun.js course, in which we built a management application for pizzerias, designed for small businesses that need to manage their daily orders and sales.

## Technologies

- Bun.js
- Elysia
- Zod
- Drizzle
- PostgreSQL
- Docker
- JWT

### Features

- Authentication via Magic Link
- Authorization via JWT Cookie
- Custom Business Metrics

## Running

```bash

bun install
bun services:up
bun migrate
bun seed
bun dev

```
